# Wiktionary register data attribution

Register labels in the bundled lexicon are partly derived from English
Wiktionary usage-category membership.

- Source: <https://en.wiktionary.org/wiki/Category:English_terms_by_usage>
- Authors: Wiktionary contributors
- Licenses: Creative Commons Attribution-ShareAlike 4.0 and GNU Free
  Documentation License; see <https://en.wiktionary.org/wiki/Wiktionary:Copyrights>

Changes made for Play the World: usage-category entries were lowercased,
restricted to unbroken ASCII alphabetic spellings, and intersected with the
game lexicon to locate review candidates. The usage labels attached to each
candidate's first English definition were reduced to the documented
representative-meaning classes, followed by explicit boundary examples and
POS-compatible inflection inheritance. Definitions are not redistributed.
